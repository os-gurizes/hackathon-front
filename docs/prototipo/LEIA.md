# Protótipo aprovado

Telas do protótipo navegável (link com o time), no formato do editor de design. Use como referência de layout, hierarquia, textos e comportamento. Não copie o formato: `<x-dc>`, `<sc-for>`, `<sc-if>`, `x-import` e `{{...}}` são do editor.

- `x-import component-from-global-scope="SalaTatica.Button"` = o primitive `Button` do design system (`design/referencia/primitives.tsx`).
- `/_blob/<id>` = imagens do pacote `assets-valorant` (minimapas, ícones de agentes, banners de mapa, elo).
- Dados são de exemplo.

| Arquivo | Tela |
|---|---|
| `Main.dc.html` | Login |
| `PlayerDesempenho.dc.html` | Player: Meu desempenho |
| `PlayerMapas.dc.html` | Player: Meus mapas (heatmap sobre o minimapa com callouts) |
| `CoachTime.dc.html` | Coach: Meu time |
| `CoachPrancheta.dc.html` | Coach: Prancheta (foco atual) |
